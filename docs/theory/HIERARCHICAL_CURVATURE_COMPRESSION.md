## 1. Exact recursive Hessian identity

For a parent node N with children c:

  H_N = sum_c w_c H_c + Cov_w(g_c)

where:
- w_c are centroid mass weights;
- g_c are child log-mass gradients;
- H_c are child log-mass Hessians.

The same identity already underlies the exact directional authority.

## 2. Hierarchical signed low-rank representation

Represent each child Hessian as

  H_c ~= U_c diag(lambda_c) U_c^T

with signed eigenvalues and rank r.

For fanout F<=4, the parent Hessian lives approximately in the span of:
- all child eigenvectors U_c;
- child gradient deviations d_c = g_c - g_N.

Candidate span size is at most:

  F*r + F.

For r=8 and F=4 this is only 36 directions.

Construct an orthonormal basis Q of this candidate span.

Project the parent Hessian into that small basis:

  A = Q^T H_N Q.

Because each H_c is already represented in Q coordinates and the covariance term is
a sum of rank-1 d_c d_c^T terms, A can be assembled without a dense D x D matrix.

Eigendecompose only A, retain the top signed modes by |eigenvalue|, and lift them back:

  U_N = Q V_r.

This gives a recursive rank-r curvature representation for every node.

## 3. Leaf Hessian representation

A B16 antipodal block Hessian at a query centroid is

  H_b = E_pi[
          alpha' c c^T
          + sech^2(h) r r^T
        ]
        + Cov_pi(g_pair).

This is itself generated by a small set of pair vectors:
- c_p;
- r_p;
- pair-gradient deviations.

So leaf compression can also be performed from a small local span rather than a
128x128 dense matrix.

At 8 pairs the raw candidate span is <=24 directions.

## 4. Runtime evaluation

For query residual delta:

  q_N = delta^T H_N delta
      ~= sum_j lambda_j (delta^T u_j)^2.

Cost per visited node:
- r D projection work if evaluated directly;
- or less if parent/child projection reuse is later derived.

First gate does not optimize projection reuse.
